# Profile

Skills and abilities you have beyond what `BASE.tex` states. Resume tailoring uses this list in one place
only. When a job posting asks for a keyword your base resume lacks, a separate Claude judge decides whether
you genuinely have it, and it treats every entry below as true. A keyword the judge approves from this list
alone can appear in the resume's skills section, never inside an experience bullet. A keyword your resume
itself implies can also go into the bullets that show it.

Write one skill per line, starting with "- ". Name the tools you have used rather than only the area: an
entry "Browser automation" does not tell the judge you have used Playwright. Headings and other text are
ignored. Leave out anything you could not discuss in an interview.
